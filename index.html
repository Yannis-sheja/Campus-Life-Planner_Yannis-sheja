About

A Campus Planner is a personal tool that helps to organize your day. It creates tasks, events, set the due dates, and also track how long each task takes so you can see where you time actually goes.

Add tags to group-related items, and uses the search bar, which helps to support regular expressions to find exactly what you need or want, from simple keywords to advanced patterns. A summary of your tracked time aids in reviewing your progress over time.

There is no need to sign-up or creating an ccount. All your data is stored locally in the browser, so it stays private and works offline. Clearing your browser data will remove it though, so it is better to export a backup if you want to keep it safe.
